# 敷地計畫｜近十年申論題庫 PWA

靜態網頁 App，含建築師敷地計畫與都市設計歷屆申論題、官方試卷出處、答題範例、個人筆記及離線快取。

## 公開網站
設定 GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。若使用 GitHub Free，儲存庫必須為 Public。
預計網址：https://yujel-0520.github.io/site-planning-study/

## 手機安裝
iPhone：Safari 開啟網站 → 分享 → 加入主畫面。
Android：Chrome 開啟網站 → 安裝 App／加入主畫面。

## 個人筆記
筆記保存在各使用者瀏覽器的 localStorage，不會上傳 GitHub；跨裝置請使用匯出、匯入 JSON 功能。

本網站為學習用整理資料，非考選部官方答案。官方試卷請以考選部網站為準。
